    # Pune School Website

Static 8-page website for a Pune school (placeholder name: Nirmaan International School).
Built with Next.js (static export), TypeScript and Tailwind CSS v4.

## Run

npm install
npm run dev
Open http://localhost:3000

## Build

npm run build
The static site is written to the out/ folder.

## Deploy

Push to main and Vercel deploys automatically.
Every pull request gets a preview URL.
